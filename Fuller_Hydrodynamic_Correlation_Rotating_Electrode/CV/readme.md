# Publication Data for "Development of A Hydrodynamic Correlation for Rotating Rod Electrodes in Molten Chloride Salts: Part II—Rotational Experiments" by Ranon Fuller and Devin Rappleye
## Subfolder Descriptions
### CV
This folder contains the raw data for the cyclic voltammograms appearing in Figure 1
### RRE_I_Lim
This folder contains subfolders of all of the raw data from our rotating rod electrode (RRE) experiments, which were used to determine the liminting current (I<sub>lim</sub>).
#### CrCl2_Deposition
This folder contains chronoamperometry (CA) data from the RRE at various rotational rates (0-2750 rpm). The rotation rate is labeled on each subfolder within this folder.
The CA data within this folder was used to generate the plot in Figure 3 and determine the limiting current values reported in Figure 4C.
#### CrCl2_Oxidation
This folder contains chronoamperometry (CA) data from the RRE at various rotational rates (0-2750 rpm). The rotation rate is labeled on each subfolder within this folder.
The CA data within this folder was used to determine the limiting current values reported in Figure 4B.
#### SmCl3_LiCl-KCl
This folder contains chronoamperometry (CA) data from the RRE at various rotational rates (0-2750 rpm). The rotation rate is labeled on each subfolder within this folder.
The CA data within this folder was used to generate the plot in Figure 2 and determine the limiting current values reported in Figure 4A.
#### SmCl3_NaCl-KCl
This folder contains chronoamperometry (CA) data from the RRE at various rotational rates (0-2750 rpm). The rotation rate is labeled on each subfolder within this folder.
The CA data within this folder was used to determine the limiting current values reported in Figure 4D.
